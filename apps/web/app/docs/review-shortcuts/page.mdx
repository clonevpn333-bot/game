# Review shortcuts

Every action on the review board has a key, and the footer of the board always shows them. This page is the full list.

## Moving and accepting

| Key                         | Action                       |
| --------------------------- | ---------------------------- |
| <Kbd>J</Kbd> / <Kbd>K</Kbd> | Next / previous document     |
| <Kbd>Enter</Kbd>            | Accept the selected document |
| <Kbd>Space</Kbd>            | Open a large preview         |

## Fixing a document

| Key                       | Action                                            |
| ------------------------- | ------------------------------------------------- |
| <Kbd>1</Kbd>–<Kbd>9</Kbd> | Move to binder category 1–9                       |
| <Kbd>T</Kbd>              | Change the form type (searchable list)            |
| <Kbd>E</Kbd>              | Edit the name                                     |
| <Kbd>R</Kbd>              | Rotate the current page                           |
| <Kbd>S</Kbd>              | Split the document at the current page            |
| <Kbd>M</Kbd>              | Merge with the previous document                  |
| <Kbd>D</Kbd>              | Mark as a duplicate and remove it from the binder |

## Everywhere

| Key                                                       | Action                                                            |
| --------------------------------------------------------- | ----------------------------------------------------------------- |
| <Kbd>Ctrl</Kbd> <Kbd>K</Kbd> or <Kbd>⌘</Kbd> <Kbd>K</Kbd> | Command palette: new binder, open client, export, theme, settings |

Category numbers follow your binder order, so <Kbd>1</Kbd> is the first category in [your template](/docs/binder-templates/). {P} never files a document on its own when two form types score close together; it marks it **Check** and shows both, so <Kbd>T</Kbd> is usually one keystroke away from the fix.
