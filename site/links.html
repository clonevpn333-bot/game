Nova Arcade

Get a link that works

The whole arcade is one file. Once the repository is public it is served by several independent content delivery networks — different companies, different domains, same file. Press Test from this device. Green means it loads as a real page — use that one. Amber means the domain is reachable but that CDN hands back the source code instead of running it (jsDelivr and Statically do this to every .html on purpose). Red is blocked.

If the repository is still private

one setting
Open your repository on GitHub → Settings.
Scroll to Danger Zone → Change repository visibility → Make public.
Come back here and press Test from this device. The CDN links start working within a minute or two — no deploy, no account.
Optional, for the nicest address: Settings → Pages → Source → GitHub Actions. That publishes USER.github.io/REPO/.
Nothing on the internet is truly unblockable — a filter can block any domain it wants. What this does is give you many unrelated domains for the same file, so one filter rule cannot take them all out. If every one is red, download the file and drop it on app.netlify.com/drop for a fresh random address on a different domain again.
