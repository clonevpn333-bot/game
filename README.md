# game

A couple of browser games. Both are plain static HTML/JS — no build step, no install.

| Game | Open | What it is |
|---|---|---|
| **Among Us 3D — Definitive Edition** | [`among-us-3d/index.html`](among-us-3d/index.html) | First-person 3D Among Us: all five maps, every role, the full task list, shop and Cosmicubes, serverless P2P multiplayer for up to 15 players with proximity voice + text chat, and AI bots. See [`among-us-3d/README.md`](among-us-3d/README.md). |

## Download

**Code ▾ → Download ZIP** on this branch, or:

```
git clone -b claude/3d-among-us-game-xhh2w3 https://github.com/clonevpn333-bot/game.git
```

Unzip, then open `among-us-3d/index.html` in a browser. No install, no build, no server.
