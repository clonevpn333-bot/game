Overclock

Blank-window launcher

Opens a new tab that stays on about:blank and loads the page inside it.

This page is open from your computer, not from a website. A blank window can only frame a page served over http or https, so put the site online first (drag the folder to netlify.com/drop) and paste that address above. To play offline right now, open portal.html directly — it needs nothing else.

If nothing opens, the browser blocked the pop-up — allow pop-ups for this page and try again. Settings are stored in this browser only.
