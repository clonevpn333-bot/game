Overclock

Blank-window launcher

Opens a new tab that stays on about:blank and loads the page inside it.

This page is open from your computer, not from a website. A blank window cannot frame a file:// address — the browser blocks it. Use the local file option below, which loads the page's own HTML instead of pointing at a URL, or put the site online and paste that address above.

Pick portal.html. Its HTML is handed straight to the window, so there is no address for the browser to refuse.

If nothing opens, the browser blocked the pop-up — allow pop-ups for this page and try again. Settings are stored in this browser only.
